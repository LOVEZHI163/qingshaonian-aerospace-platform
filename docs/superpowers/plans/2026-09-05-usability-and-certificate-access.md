# 报名体验与免注册领证实施计划

Goal: 按用户确认顺序完成指南、默认赛事、登录状态、填写保护，然后扩展代报名队员领证与短信集中报名验证。

Architecture: 默认公开赛事复用官网选择策略；登录请求统一加锁；表单离开保护封装成可复用组合函数。证书入口使用独立短信用途和限定队员范围的短时凭据，复用现有证书访问规则与短信持久化限流。

Constraints: 一个手机号注册一个账号；报名填写学生真实身份证；不声称已联网实名核验。不把身份证明文持久化到浏览器；不发送未经指定的真实测试短信。

## 第一批

- [x] 指南 HTML 对齐手机号注册、学生身份报名规则，去除不存在的身份勾选和联网核验说明。检查了下载 PPT 的文本，其不含上述三项错误措辞；本批未改写 PPT。
- [x] `services/events.js` 的公开默认赛事使用 `selectHomeEvents`，保留报名接口自身的显式赛事/多赛事保护；无可展示赛事返回空数据。
- [x] `App.vue` 登录进行中保护、侧栏状态重置；`AuthPage.vue` 密码/短信按钮反馈一致。回归测试覆盖重复提交、失败重试、退出后重登。
- [x] 个人报名与组织报名表注册离开保护；提交成功清除脏状态；菜单、退出和页面卸载均提示。测试覆盖取消离开、确认离开、成功提交不提示。
- [ ] 构建、相关 API/Admin 测试、浏览器验证、server115 备份与部署、版本一致性检查。

## 第二批

- [ ] 自助查询凭据限定用途、期限和具体身份；预览/下载都重新校验；无账号自动创建。错误不泄露身份证或其他队员信息。
- [ ] 模拟同学校共享出口、多手机号、跨用途验证码、错误码重试、限流和过期，使用假短信发送器测量集中报名限制，不触发真实短信费用。
