# 赛事海报悬浮文案对齐设计

## 目标

调整首页赛事海报的桌面悬浮信息层，使标题、日期地点和操作按钮更贴合海报自身的左侧文字安全区，减少悬浮标题与海报原始标题重叠造成的拥挤感。

## 已确认设计

- 仅调整支持悬停的桌面布局；手机端继续采用“完整海报在上、赛事信息在下”的现有结构。
- 悬浮文案仍保持左对齐，但整体向下移动约 40–50 像素，使其落在海报左侧下方的可读区域。
- 桌面端悬浮标题最大字号适度缩小，避免盖住海报原始主标题；赛事名称内容、报名时间、地点和两个按钮不变。
- 标题、时间地点和按钮使用同一条左侧对齐线，不改变两个按钮的跳转目标。
- 鼠标悬停、键盘聚焦、减少动画偏好和移动端触控行为保持不变。

## 验收标准

- 桌面端悬停或键盘聚焦后，文案较当前版本明显下移，并与海报左侧构图协调。
- 悬浮标题不再占据海报顶部主要标题区域。
- 时间、地点和按钮的左边缘一致。
- 手机端结构、按钮尺寸和无横向溢出行为无回归。
- 前端相关测试、全量测试和生产构建通过，部署后正式站可访问。
