# 赛事信息页海报头图与导航统一设计

## 1. 目标

本次优化聚焦公开官网的赛事信息页与顶部导航，解决以下问题：

- `/about` 和 `/rules` 的标题、抽屉名称不统一；
- 赛事信息页头部仍使用通用渐变色，没有利用后台已绑定的赛事海报；
- 约 1224px 宽度下品牌、主导航和“用户登录 / 报名入口”互相挤压，出现不齐和裁切；
- 页面在不同赛事之间切换时，视觉与媒体需要跟随所选赛事，而不是写死当前海报。

本次不调整后台数据结构、不新增接口、不改变现有路由含义。

## 2. 信息架构与名称

“关于大赛”桌面抽屉和移动端手风琴统一为：

| 导航名称 | 路由 | 页面主标题 |
| --- | --- | --- |
| 大赛简介 | `/about` | 大赛简介 |
| 大赛章程 | `/rules` | 大赛章程 |

删除公开端界面中混用的“赛事简章”“赛事章程”“赛事介绍”等同义名称。后台保存的业务字段和接口值不变，仅统一公开端展示文案。

## 3. 赛事海报头图

### 3.1 数据来源

- 头图读取当前 URL 所选赛事的 `hero` 媒体；
- 复用现有赛事媒体组件与响应式图片地址，不硬编码媒体 ID 或服务器 URL；
- 切换 `?event=` 后，头图、赛事名称和正文一起切换；
- 当前赛事无海报或图片加载失败时，保留现有蓝紫渐变作为兜底，不显示破图。

### 3.2 视觉方案（已批准方案 A）

- 海报全宽铺满头图卡片，采用 `cover`，允许上下或两侧轻微裁切；
- 图片焦点默认居中，保持赛事主标题和核心视觉位于可见区域；
- 左侧叠加深蓝到透明的横向蒙层，右侧保留海报原有蓝紫色与光效；
- 文案位于左侧安全区，展示赛事名称、页面标题和赛事宣传语；
- 桌面端头图维持海报横幅比例并设置合理最小高度；移动端提高蒙层强度，确保白字可读；
- 海报作为装饰背景，不重复朗读；赛事名称和页面标题由可见文字及语义标题完整表达。

## 4. 页面结构与对齐

- 头图下方保持“比赛时间 / 比赛地点 / 报名截止”三张等宽信息卡；
- 桌面端三列严格等高、同间距；窄屏按现有规则折为单列；
- 正文内容卡保持两列，在移动端折为单列；
- 页面容器、头图、信息卡和正文卡使用同一内容宽度与左右边线；
- 长赛事名、地址、日期允许安全换行，不产生横向滚动。

## 5. 顶部导航响应式修正

### 5.1 宽屏桌面

- 品牌、主导航、登录操作区采用“品牌 / 自适应导航 / 操作按钮”三段布局；
- 缩小品牌字标的最大占用宽度，给主导航和右侧按钮预留稳定空间；
- 主导航文字保持同一基线和相同点击高度；
- “用户登录”“报名入口”始终完整显示，不允许被窗口边缘裁切。

### 5.2 中窄屏

- 将桌面导航切换到移动抽屉的断点提前到约 `1280px`；
- 在用户截图对应的约 1224px 宽度下，显示紧凑品牌名与菜单按钮，不再强行挤入完整桌面导航；
- 移动抽屉保留全部公开导航、用户登录和报名入口，信息架构与桌面一致；
- 390px 至 1280px 范围不得出现横向裁切或页面级横向滚动。

## 6. 状态与降级

- 首页赛事数据仍在加载时，页面保持稳定结构；
- 赛事详情接口失败时继续显示已有公开赛事基础信息，并保留重试提示；
- 无赛事海报时使用品牌渐变背景；
- 无事实字段时不渲染空白信息卡；
- 多赛事切换不共享或串用上一赛事的海报。

## 7. 可访问性

- 页面只保留一个主 `h1`；
- 抽屉按钮、链接、登录和报名按钮保持键盘可达与清晰焦点环；
- 海报蒙层后的标题和正文满足可读对比度；
- 移动端触控目标不低于 44px；
- 减少动态效果偏好继续生效，不新增强制动画。

## 8. 验收范围

### 功能验收

- `/about?event=wz-aerospace-2026` 显示当前赛事海报与“大赛简介”；
- `/rules?event=wz-aerospace-2026` 显示同一赛事海报与“大赛章程”；
- “关于大赛”抽屉只显示“大赛简介 / 大赛章程”，路由正确；
- 切换另一赛事后使用该赛事自己的海报或渐变兜底；
- 登录与报名入口保持原有跳转。

### 视觉与响应式验收

- 1440px：桌面导航、品牌、按钮完整对齐；
- 1280px 与 1224px：进入紧凑抽屉导航，无挤压和裁切；
- 1024px、768px、390px：头图文案可读、信息卡自然折叠、无横向溢出；
- 键盘可以打开和关闭导航，并在关闭后恢复焦点。

## 9. 测试与发布

- 先补失败测试，再修改导航文案、页面标题、头图结构和 CSS；
- 运行公开站聚焦测试、公开站全量测试和生产构建；
- 在真实浏览器检查 1440 / 1224 / 390 三个关键宽度；
- 验证通过后部署到现有 ECS，并对 `https://aerogp.cn/about` 与 `https://aerogp.cn/rules` 做线上冒烟检查。
