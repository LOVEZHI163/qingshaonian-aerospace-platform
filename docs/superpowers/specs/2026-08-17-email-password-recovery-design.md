# 邮箱密码找回与账号安全设计

## 1. 目标与范围

本次升级在现有手机号登录和短信验证码找回密码基础上，增加通过已验证邮箱发送一次性重置链接的找回方式。

系统仍以手机号作为登录账号，不支持直接使用邮箱登录。个人用户、组织负责人和平台管理员统一支持绑定、验证和更换邮箱。短信验证码找回继续保留，邮箱找回不使用验证码。

老账号不强制补录邮箱；未绑定并验证邮箱的账号仍可使用短信验证码或管理员临时密码重置。新用户注册成功后引导绑定邮箱，但不阻断注册和首次登录。

## 2. 用户流程

### 2.1 邮箱绑定

登录用户在“账号安全”页面输入当前密码和待绑定邮箱。系统校验当前密码、邮箱格式及唯一性后发送验证链接。链接验证成功后，邮箱才被标记为可用于找回密码。

验证链接有效期为 30 分钟。同一用户重新申请后，之前未使用的验证链接立即失效。

### 2.2 更换邮箱

用户输入当前密码和新邮箱，系统向新邮箱发送验证链接。新邮箱验证成功前，原邮箱保持有效；验证成功后才原子替换绑定邮箱，并向原邮箱发送安全通知。

### 2.3 邮箱找回密码

用户在“忘记密码”页面选择“邮箱链接找回”，输入已绑定邮箱。接口始终返回统一提示：

> 如果该邮箱已绑定并完成验证，重置密码邮件将在几分钟内发送，请同时检查垃圾邮件目录。

邮件包含指向 `https://aerogp.cn/admin/?view=resetPassword&token=...` 的一次性链接。用户打开链接后输入两次新密码；校验通过后更新密码、作废令牌并注销该账号的其他登录会话。

重置链接有效期为 10 分钟，只能使用一次。重新申请重置邮件时，该用户之前所有未使用的密码重置链接立即失效。

### 2.4 手机找回密码

现有短信验证码找回流程和安全限制保持不变。邮箱服务不可用或账号未绑定邮箱时，页面引导用户选择手机验证码或联系平台管理员。

## 3. 数据模型

`users` 墋加以下字段：

- `email`：规范化后的绑定邮箱，可为空，全局唯一；
- `email_verified_at`：邮箱验证完成时间；
- `email_updated_at`：邮箱最后修改时间。

新增邮箱验证令牌表，包含用户编号、待验证邮箱、令牌摘要、创建时间、失效时间和使用时间。

新增密码重置令牌表，包含用户编号、令牌摘要、创建时间、失效时间、使用时间、请求 IP 和必要审计元数据。

数据库只保存随机令牌的加密摘要，不保存邮件链接中的原始令牌。历史用户新增字段保持空值，不要求迁移或补录邮箱。

## 4. 安全设计

- 邮箱地址入库前统一去除首尾空格并转换为小写；唯一性比较使用规范化值。
- 绑定和更换邮箱必须校验当前密码。
- 公开找回接口不透露邮箱是否存在、账号状态或邮箱验证状态。
- 同一邮箱每小时最多申请 5 次，同一 IP 每小时最多申请 20 次，连续申请冷却 60 秒。
- 令牌使用密码学安全随机数生成，原始值只出现在邮件链接中。
- 重置链接过期、已使用、已被替代或账号不可用时统一显示“链接已失效，请重新申请”。
- 新密码复用现有密码强度校验；前端要求输入两次，后端仅信任最终提交并独立校验。
- 重置成功后递增用户 `sessionVersion`，使其他设备的会话全部失效。
- 邮件发送、邮箱验证、邮箱更换和密码重置写入审计日志；日志不得记录完整令牌、密码或敏感邮件正文。
- 邮件发送失败时清除或禁用对应令牌，不能留下未实际投递但仍有效的重置入口。

## 5. 界面设计

个人用户、组织负责人和平台管理员现有“修改密码”页面统一升级为“账号安全”，包含：

- 当前手机号；
- 邮箱绑定与验证状态；
- 绑定邮箱；
- 重新发送验证邮件；
- 更换邮箱；
- 修改密码。

忘记密码页面提供两个清晰选项卡：

- 手机验证码找回；
- 邮箱链接找回。

邮箱重置页面包含新密码、确认新密码、密码规则提示和确认按钮。链接无效时显示重新申请入口，不渲染密码表单。

平台管理员的用户列表可查看邮箱绑定和验证状态，但不能查看验证链接、重置令牌、用户当前密码或新密码。

## 6. 接口设计

建议增加以下接口能力：

- 登录用户申请绑定或更换邮箱；
- 公开验证邮箱链接；
- 登录用户重新发送邮箱验证邮件；
- 公开申请邮箱密码重置；
- 公开验证重置令牌状态；
- 公开使用有效令牌提交新密码。

绑定、更换和重置服务共用统一的令牌生成、摘要、过期判断、限流、审计和邮件投递封装。前端根据稳定错误代码显示中文提示，不解析底层阿里云错误文本。

## 7. 阿里云 DirectMail

生产环境使用阿里云邮件推送 DirectMail，采用按量付费和共享 IP，不购买独立 IP 或预付费资源包。

建议配置：

- 发信域名：`mail.aerogp.cn`；
- 发信地址：`no-reply@mail.aerogp.cn`；
- 显示名称：温州市青少年航空航天创新比赛；
- 网站基础地址：`https://aerogp.cn`。

阿里云访问凭据、发信地址和网站基础地址仅通过服务器环境变量提供，不写入代码仓库或前端构建产物。域名需在阿里云控制台完成验证，并配置要求的 SPF、DKIM 等 DNS 记录。

邮件服务设置每日发送上限、费用预警和异常发送监控。应用侧对可重试故障执行有限重试，不对参数、权限或域名配置错误无限重试。

## 8. 邮件内容

验证邮箱邮件应说明请求用途、有效时间、操作按钮和“非本人操作可忽略”。密码重置邮件应包含账号安全提醒，但不显示完整手机号、当前密码或其他个人资料。

密码重置成功后向已验证邮箱发送安全通知。更换邮箱成功后向原邮箱发送变更通知，通知中提供联系平台管理员的方式。

## 9. 测试与验收

后端测试至少覆盖：

- 三类账号绑定、验证和更换邮箱；
- 邮箱唯一性和规范化；
- 未验证邮箱不能用于找回；
- 不存在、未验证和停用账号返回相同公开响应；
- 10 分钟过期、一次性使用和新链接替代旧链接；
- 频率限制与冷却；
- 发送失败时令牌不可使用；
- 密码重置后旧密码和旧会话失效；
- 短信验证码原有流程不回归。

前端测试至少覆盖：

- 三类账号安全页面的一致行为；
- 绑定、待验证、已验证状态；
- 手机和邮箱找回选项切换；
- 邮箱重置成功、过期和重复使用提示；
- 桌面端与手机端可操作性。

上线前在测试环境完成真实邮件投递、垃圾邮件目录检查、主流邮箱收信验证、完整 API 测试、管理端测试和生产构建。数据库迁移必须向后兼容，部署后未绑定邮箱的老账号仍可正常登录。

## 10. 非目标

本次不实现邮箱验证码登录、不将邮箱改为登录账号、不要求历史用户强制补录邮箱、不允许平台管理员查看用户密码，也不自建 SMTP 邮件服务器。
