# 官网图片媒体管理设计

## 目标

在赛事管理后台的“官网内容”中增加独立的“媒体管理”页签，让平台管理员统一查看、搜索、复用、下载、替换和安全清理已经上传的官网图片，同时避免误删仍被首页、赛事或文章引用的文件。

本期只管理 `site-media` 中的官网图片：默认宣传图、分享封面、赛事封面、文章封面、正文图片和图片附件。参赛作品、作画视频、证书文件及组织资质文件继续由各自业务模块管理，不混入官网媒体库。

## 方案选择

### 方案 A：在“官网内容”中增加“媒体管理”页签（采用）

沿用“首页设置 / 赛事视觉 / 内容发布”的现有信息架构，增加第四个页签“媒体管理”。管理员无需学习新的侧边栏模块，图片和官网内容也保持在同一业务区域。

### 方案 B：增加一级侧边栏“媒体管理”

入口更醒目，但会继续加长已有侧边栏，而且容易让人误以为该页面同时管理证书、参赛作品和视频。本期不采用。

### 方案 C：只增强现有“选择图片”弹窗

改动最小，但无法完整呈现容量、引用位置、批量选择和安全清理流程，也不能解决首页及赛事图片缺少统一管理入口的问题。本期不采用。

## 页面结构

“媒体管理”页签由四个区域组成：

1. **概览卡片**：图片总数、总容量、已引用数量、未引用数量。
2. **筛选栏**：关键词、所属赛事、用途、引用状态；关键词匹配文件名和媒体 ID。
3. **图片网格**：缩略图、文件名、媒体 ID、上传时间、尺寸、大小、所属赛事、用途和引用状态。
4. **批量操作栏**：全选当前页、下载所选、删除所选未引用图片。

每张图片提供“预览”“下载”“替换”“删除”操作。已引用图片的删除按钮禁用，并显示具体引用位置；未引用图片删除前显示二次确认。批量删除只处理未引用图片，若选择中包含已引用图片，确认框明确列出跳过数量，后端再次校验引用状态。

## 引用位置

后端返回所有引用，而不是只返回第一处引用。引用类型包括：

- 首页默认宣传图
- 首页分享封面
- 赛事封面（包含赛事名称）
- 文章封面（包含文章标题）
- 文章附件（包含文章标题）
- 文章正文（包含文章标题）

前端在卡片上显示首条引用和引用总数，点击后展开完整列表。引用判断以服务器数据为准，不能仅依赖前端缓存。

## 接口设计

### 查询媒体

扩展 `GET /api/admin/site-media`：

- 参数：`page`、`limit`、`q`、`eventId`、`purpose`、`reference=all|referenced|unreferenced`。
- 返回：`rows`、`pagination`、`summary`。
- 每行增加 `references`、`referenceCount`、`referenced` 和 `downloadUrl`。
- 默认每页 24 张，最大 100 张。

现有正文图片选择弹窗继续使用同一接口，并保持 `kind=image&limit=100&q=` 的兼容行为。

### 下载媒体

新增 `GET /api/admin/site-media/:id/download`，使用原始文件名并设置附件下载响应头。仅平台管理员可以访问。

### 批量删除

新增 `POST /api/admin/site-media/bulk-delete`，请求体为 `{ ids: string[] }`，最多 100 个。接口逐项重新检查引用，返回 `deleted`、`skipped` 和每项原因。物理删除沿用现有清理日志与失败恢复机制。

### 替换媒体

新增 `POST /api/admin/site-media/:id/replace`（multipart）。后端先以新媒体 ID 完成校验、图片规范化和多尺寸生成，再在一次数据库写入中把旧 ID 的全部引用迁移到新 ID，包括正文 HTML 中的公开媒体地址。数据库写入成功后，旧文件进入清理日志；失败时删除新文件并保留旧引用。

替换是全局操作，会影响所有引用位置。前端确认框必须显示受影响引用数量和位置。替换成功后返回新媒体记录，页面刷新列表。

## 安全规则

- 只允许平台管理员访问媒体管理接口。
- 所有删除和替换在后端重新计算引用，防止并发页面造成误删。
- 已引用图片不能通过单项或批量删除接口删除。
- 替换文件必须符合原媒体用途对应的文件类型和大小策略。
- 不直接在服务器目录中手工删除文件。
- 预览使用私有、禁止缓存的管理员预览接口；下载使用附件响应头。
- 批量操作最多 100 个 ID，并去重、校验 ID 格式。

## 错误处理

- 列表加载失败：保留筛选条件并显示“重新加载”。
- 图片预览失败：显示占位图，不影响其余卡片操作。
- 删除冲突：显示最新引用位置并刷新该行。
- 批量删除部分成功：分别显示已删除和已跳过数量，不把部分成功误报为整体失败。
- 替换失败：旧图片及引用保持不变；显示后端返回原因。
- 下载失败：显示错误提示，不触发页面跳转。

## 测试与验收

### 后端

- 列表分页、筛选、汇总和全部引用位置。
- 已引用图片拒绝删除，未引用图片可删除。
- 批量删除的全部成功、部分跳过、重复 ID 和数量上限。
- 下载文件名与响应头。
- 替换成功时迁移所有引用和正文 HTML。
- 替换写库失败时回滚新文件并保留旧媒体。

### 前端

- “官网内容”显示第四个“媒体管理”页签。
- 搜索、赛事、用途和引用状态筛选正确传参。
- 网格显示元数据和引用位置。
- 已引用图片删除按钮禁用。
- 批量删除确认、部分跳过提示和结果刷新。
- 替换确认显示影响范围并上传新图。
- 760px 以下单列布局，无横向溢出，触控按钮不小于 44px。

### 线上验收

- 管理员能找到并复用已有官网图片。
- 已引用图片不会被误删。
- 未引用图片可单项或批量删除，服务器容量相应下降。
- 替换首页、赛事和文章图片后，公开网页显示新图且旧引用不残留。

## 不在本期范围

- 参赛作品图片和视频管理。
- 证书文件管理。
- 组织营业执照及授权书管理。
- 自动压缩历史视频或对象存储迁移。
- 普通用户和组织负责人访问媒体库。
