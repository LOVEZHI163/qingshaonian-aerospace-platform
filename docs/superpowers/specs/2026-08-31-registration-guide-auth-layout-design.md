# 注册指南与登录页布局优化设计规格

## 目标

精简注册指南中不再需要的说明内容，并统一密码登录、短信验证码登录的操作布局。该变更不改变注册开放状态、短信认证业务规则或账号权限。

## 注册指南

- 删除整个“注册指南目录”卡片。
- 删除整个“阅读前提示”章节。
- 删除整个“一、名词概念介绍”章节。
- 将原“二、操作前注意事项”改为“一、操作前注意事项”。
- 将原“三、账号注册流程操作说明”改为“二、账号注册流程操作说明”。
- 删除只服务于已移除目录和章节的无用 CSS。
- 保留其余正文、下载入口、嵌入模式和响应式布局。

## 登录页

- 密码登录把“忘记密码？”放在密码输入区域下方右侧。
- 密码登录主按钮放在操作区下方并占满表单宽度。
- 短信验证码登录使用相同的完整宽度主按钮和垂直节奏。
- “获取验证码”继续位于验证码输入框旁，并保持桌面端与移动端可用。
- 不改变密码登录、短信登录、注册和密码重置 API。
- 不显示测试账号或测试密码。

## 响应式与可访问性

- 桌面端和移动端不得出现按钮重叠、忘记密码漂移、操作区溢出或窄按钮。
- 主登录按钮保留明确的可访问名称、禁用状态和键盘提交行为。
- “忘记密码？”保持按钮语义并可通过键盘访问。

## 测试与发布

- 更新公共站点部署测试，明确断言被删除的三个区块不再存在，并断言两个重新编号的标题存在。
- 更新 `AuthPage` 组件测试，分别验证密码和短信表单的完整宽度主操作以及忘记密码位置。
- 运行 API 公共站点测试、管理端测试与生产构建。
- 与团队报名功能完成全量回归后部署到 `server115:/opt/aerogp`，并在真实移动宽度和桌面宽度进行冒烟检查。
