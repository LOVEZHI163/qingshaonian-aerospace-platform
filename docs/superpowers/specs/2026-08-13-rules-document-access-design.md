# 大赛章程在线查看与下载设计

## 目标

在 `wz-aerospace-2026` 的“大赛章程”公开页面提供两个稳定入口：浏览器在线查看 PDF，以及下载原始 DOC 文件。

## 交互设计

- 章程正文卡片之后显示“章程文件”卡片。
- “在线查看章程”在新标签页打开 PDF，并使用 `noopener` 防止新页面控制原页面。
- “下载章程原文件”下载原始 DOC，保留正式中文下载文件名。
- 桌面端按钮横向排列；窄屏端纵向排列并占满可用宽度。
- 仅当前温州赛事的 `rules` 页面显示，不向其他赛事错误复用该章程。

## 文件与数据

- 源文件：`赛事方案/大赛章程.doc`。
- 网站静态文件：
  - `/documents/wz-aerospace-2026-rules.pdf`
  - `/documents/wz-aerospace-2026-rules.doc`
- 章程资源元数据由当前赛事内容配置提供，页面组件只消费标准化后的 `document` 数据，不硬编码赛事判断。

## 质量与安全

- 使用 LibreOffice 将 DOC 转换为 PDF。
- 对 PDF 执行页数、文本和逐页 PNG 渲染检查。
- 自动化测试覆盖入口只在指定赛事章程页出现、PDF 新标签属性和 DOC 下载属性。
- 部署后验证页面、PDF、DOC 均返回 200，并核对文件类型和下载响应。
