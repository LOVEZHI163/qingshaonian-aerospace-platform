# 官网内容预览功能设计

## 1. 背景与目标

管理员在“官网内容”中维护首页设置、赛事视觉和公开内容时，目前只能保存后再到公共网站核对效果。这会让尚未确认的文案、图片或布局进入保存状态，也增加在后台与官网之间反复定位页面的成本。

本功能提供两种互补预览：

- **预览已保存官网**：打开公共网站当前已经保存、已经公开的数据，用于核对线上实际状态。
- **预览当前草稿**：在不保存、不发布、不改变数据库的前提下，预览管理员表单内尚未保存的内容。

目标是在“官网内容”页面内形成清晰、安全、可追溯的预览入口，同时复用公共网站真实组件，尽量保证预览与最终展示一致。

## 2. 非目标

- 不把预览当作新的发布流程，也不改变现有保存、定时发布、上线或下线状态。
- 不为普通用户开放草稿预览。
- 不把草稿写入数据库、服务器缓存、审计业务表或公共 API。
- 不提供长期有效、可转发给他人的预览链接。
- 不在本期实现多人协作批注、版本对比或预览历史。
- 不重写公共网站现有首页、赛事详情和内容详情组件。

## 3. 管理端交互

### 3.1 顶部操作

在“官网内容”页标题右侧、现有“刷新”按钮旁增加：

1. **预览已保存官网**
2. **预览当前草稿**

两个按钮均在新标签页打开，避免管理员丢失正在填写的内容。

### 3.2 按当前标签决定预览目标

- **首页设置**：草稿预览打开公共网站首页 `/preview?token=...`。
- **赛事视觉**：草稿预览打开当前选中赛事的详情预览；未选中赛事时按钮禁用，并提示“请先选择赛事”。
- **内容发布**：草稿预览打开当前正在编辑的公告、新闻、优秀作品或赛事回顾详情；没有编辑对象时按钮禁用，并提示“请先选择或新建内容”。

“预览已保存官网”也遵循相同上下文：首页打开 `/`，赛事视觉打开已保存的赛事详情页，内容发布打开已保存的内容详情页。若对象尚无稳定公开地址，则按钮禁用并解释原因。

### 3.3 预览页提示

草稿预览页顶部显示固定但不遮挡主要内容的状态条：

- 文案：“草稿预览 · 未保存 · 仅当前浏览器可见”
- 显示剩余有效时间或到期时间
- 提供“返回管理后台”按钮

预览页必须添加 `noindex, nofollow`，并在视觉上与正式官网明确区分，但主体页面仍使用真实公共组件和响应式布局。

## 4. 总体架构

草稿内容不进入服务端持久化。系统采用“管理员校验 + 浏览器短期快照 + 公共组件渲染”流程：

1. 管理端从当前标签对应的表单组件收集完整草稿。
2. 管理端调用仅管理员可访问的无状态预览校验 API。
3. API 按正式保存规则完成字段规范化、富文本过滤、资源权限检查和响应结构组装，但不执行任何写入。
4. 管理端生成密码学随机 token，将规范化结果以带版本和过期时间的快照保存到当前浏览器存储。
5. 管理端新开 `/preview?token=...`。
6. 公共 React 应用读取同源浏览器存储中的快照，校验 token、版本、类型和有效期。
7. 预览路由按照快照类型调用现有首页、赛事详情或内容详情展示组件。
8. 到期后快照被删除；非法、缺失或过期 token 显示明确错误页，不回退展示其他草稿。

该设计保证刷新预览标签页仍能短期查看，同时不向其他浏览器、访客或公共 API 暴露草稿。

## 5. 草稿快照格式

浏览器存储使用独立命名空间，例如：

```json
{
  "version": 1,
  "token": "随机且不可预测的标识",
  "kind": "homepage | event | content",
  "createdAt": "ISO 时间",
  "expiresAt": "ISO 时间，默认创建后 15 分钟",
  "adminReturnPath": "/admin/",
  "payload": {},
  "context": {
    "eventId": null,
    "contentId": null
  }
}
```

约束：

- token 使用浏览器加密随机源生成，不能使用时间戳或连续编号。
- 每个 token 对应一个快照，默认有效期 15 分钟。
- 创建和读取时都清理同命名空间内的过期记录。
- 快照只包含渲染所需的公开字段，不保存管理员身份、会话、手机号、内部备注或其他敏感字段。
- 不在 URL 中携带正文、图片数据或其他业务内容，URL 只包含 token。
- 图片不得以大体积 Base64 永久写入存储；未保存的新图片使用短期对象地址，并在无法跨标签安全复用时明确提示先上传素材。

## 6. 校验 API

新增管理员专用、无状态的预览规范化接口。接口按预览类型接收草稿，例如：

- `POST /api/admin/site-preview/homepage`
- `POST /api/admin/site-preview/event`
- `POST /api/admin/site-preview/content`

接口职责：

- 验证管理员会话和临时密码限制。
- 使用与正式保存相同的字段长度、枚举、关联对象和资源归属规则。
- 过滤富文本中的脚本、事件属性、危险 URL 和未授权嵌入。
- 将草稿与必要的只读业务数据合成为公共组件需要的视图模型。
- 对媒体引用返回受控预览地址或可验证的资源描述。
- 返回规范化预览数据，不创建或更新数据库记录，不改变发布时间、发布状态或 slug。

为了防止“保存规则”和“预览规则”长期分叉，字段校验、富文本过滤和视图模型转换应抽取为可复用纯函数，保存接口与预览接口共同调用。

## 7. 三类预览数据

### 7.1 首页设置

草稿覆盖平台名称、简介、主办单位、联系方式、备案号、SEO 信息、默认宣传图、分享封面和首页重点赛事选择。进行中赛事、已发布公告等业务集合仍从当前只读数据获得；草稿只覆盖管理员正在编辑的站点设置。

### 7.2 赛事视觉

以选中赛事的只读业务事实为基础，包括赛事名称、日期、地点、报名状态、赛项和组别；草稿覆盖官网公开地址、显示顺序、公开开关、宣传语、摘要和封面等视觉字段。预览不修改赛事发布状态。

### 7.3 内容发布

草稿包含内容类型、所属范围、所属赛事、标题、摘要、正文、封面、附件、置顶和展示时间等公开字段。预览忽略“草稿、定时发布、已发布、已下线”对公共可见性的限制，仅用于管理员查看当前编辑结果，并在状态条中明确其未发布性质。

## 8. 公共端路由与组件复用

公共端增加统一 `/preview` 路由。路由读取快照后按 `kind` 分发：

- `homepage` → 复用平台首页展示组件
- `event` → 复用赛事详情展示组件
- `content` → 复用内容详情展示组件

页面组件应接收视图模型作为输入。正式页面的数据加载器继续请求公共 API；预览页面的数据加载器改为读取经过校验的快照。两条路径最终进入同一展示组件，避免维护两套页面。

预览路由不进入公共导航、站点地图、搜索索引、分享规范链接或历史赛事链接生成逻辑。

## 9. 媒体处理

- 已上传但未公开的媒体通过管理员会话保护的预览读取接口展示。
- 已公开媒体可继续使用现有公共读取地址。
- API 必须校验媒体归属和管理员权限，不能接受任意服务器路径或外部危险 URL。
- 管理员退出登录后，受保护媒体可以在预览中失效；页面应显示占位图和“预览资源需要重新登录”的提示，而不是暴露资源。
- 临时浏览器对象地址在预览标签关闭或快照过期时释放。

## 10. 安全与隐私

- 校验 API 仅允许管理员访问，并沿用现有 CSRF、会话和审计安全边界；预览请求本身不写业务审计数据。
- 草稿快照只存在同源浏览器，不经 URL、日志或公共接口传输完整内容。
- token 具有高熵、短时效和类型校验；读取到不匹配的数据立即拒绝。
- 富文本在进入浏览器存储前完成服务端过滤，公共端渲染时仍使用安全渲染策略。
- 预览页设置 `robots` 元信息和响应侧搜索禁止策略（部署能力允许时同时设置 `X-Robots-Tag`）。
- 预览页不得加载管理端敏感数据，也不能通过 token 请求其他管理员的草稿。
- 浏览器存储不是秘密保险箱，因此严禁快照包含密码、凭据、手机号、审核备注等敏感信息。

## 11. 状态、错误与降级

- 表单校验失败：停留管理端，定位字段并显示正式保存规则对应的错误。
- 无赛事或内容上下文：禁用草稿预览按钮，不创建空快照。
- token 不存在、格式错误或类型未知：显示“预览链接无效”。
- 快照已过期：删除记录，显示“预览已过期，请返回后台重新生成”。
- 存储空间不足：提示管理员关闭旧预览或清理浏览器站点数据，不自动保存草稿。
- 受保护图片失效：保留页面布局并显示资源占位，不导致整页白屏。
- 公共 API 的辅助只读数据失败：显示预览不可用和重试入口，不使用可能误导的旧数据。
- 弹窗被浏览器拦截：保留已经生成的预览 URL，并提供可点击的“打开预览”提示。

## 12. 测试与验收

### 12.1 管理端

- 两个预览按钮在官网内容页正确显示，刷新功能保持不变。
- 已保存官网预览根据三个标签和当前选中对象打开正确正式路由。
- 草稿预览收集尚未保存的表单值并调用对应校验接口。
- 未选择赛事或内容时按钮禁用且提示准确。
- 接口报错、浏览器弹窗拦截和存储失败均有可恢复提示。
- 预览动作不触发任何保存、发布或下线请求。

### 12.2 API

- 三类接口只有管理员可访问。
- 输入使用正式保存规则校验，并验证富文本过滤结果。
- 返回值不包含敏感字段。
- 调用前后数据库和发布状态完全不变。
- 未授权媒体、错误关联对象和危险 URL 被拒绝。

### 12.3 公共端

- 三类合法快照分别渲染首页、赛事详情和内容详情。
- 预览使用与正式页面相同的展示组件。
- 错误 token、篡改版本、错误类型和过期快照均进入对应错误状态。
- 页面包含草稿状态条、返回后台入口以及 `noindex, nofollow`。
- 预览内容不会出现在正式首页、列表、站点地图或搜索元信息中。
- 360px、768px、1440px 下预览布局与正式页面保持一致。

## 13. 发布与回退

- 先部署兼容新预览视图模型的公共端和无状态 API，再开放管理端按钮，避免旧公共端无法识别快照。
- 功能不涉及数据库迁移，回退时可直接隐藏管理端入口并移除 `/preview` 路由和校验接口。
- 旧浏览器快照因版本或路由不存在自然失效，不影响正式官网数据。
- 上线后记录校验失败率和预览页前端错误，但不得记录草稿正文或 token 完整值。

## 14. 完成标准

管理员可以在“官网内容”的三个标签中：

1. 一键打开当前已保存官网页面；
2. 在不保存、不发布、不修改数据库的情况下打开当前草稿预览；
3. 清晰识别草稿预览及其有效期；
4. 遇到无选择、过期、权限或媒体错误时获得明确恢复指引；
5. 确认预览与最终公共页面复用同一套展示组件，并且草稿不会被普通访客看到。
