# 主导航间距与抽屉宽度微调设计

## 目标

改善桌面端顶部主导航的舒展感，并减少下拉抽屉两侧多余留白。

## 设计

- 桌面端五项主导航的横向间距由 `1.5rem`（24px）调整为 `2rem`（32px）。
- 每个模块下拉抽屉的固定宽度由 `11rem`（176px）调整为 `9.5rem`（152px）。
- 主导航继续保持居中；登录与报名按钮保持原位置、尺寸和视觉层级。
- 主导航与抽屉现有字号、字重、居中方式、悬停及键盘交互保持不变。
- 移动端导航结构和样式不做调整。

## 响应式约束

- 在 1294px 桌面视口中，五项导航不得换行，且不得与右侧登录、报名按钮重叠。
- 在桌面断点边缘保持无横向溢出；进入移动断点后沿用现有移动导航。
- 抽屉中的“大赛简介”“新闻动态”等较长文字必须保持单行可读，并保留必要的左右留白。

## 验证

- 先用样式回归测试固定 `gap: 2rem` 与 `inline-size: 9.5rem`，确认测试在实现前失败、实现后通过。
- 运行 Web 全量测试和项目全量构建。
- 使用真实浏览器检查 1294px、桌面断点边缘和 390px 三种宽度，确认无换行、重叠或横向溢出。
- 部署前备份数据库、上传文件、源代码和当前容器镜像；部署后运行发布校验和完整冒烟测试。
