# 注册指南文档网页化设计

## 1. 目标

将现有公开页面 `/registration-guide?event=wz-aerospace-2026` 中旧版“两块报名流程”替换为用户提供的《注册指南(1).docx》完整内容，并将《注册指南(1).pptx》作为可下载的图文指南资源。

本次只调整公开报名指南的展示内容和静态下载资源，不修改注册、登录、组织审核、报名提交等业务逻辑。

## 2. 内容来源

- 网页正文唯一来源：工作区根目录的 `注册指南(1).docx`。
- 下载资源：工作区根目录的 `注册指南(1).pptx`。
- DOCX 当前包含完整说明正文和 10 张正文图片（7 张普通内嵌图片、3 张浮动图片）。
- PPTX 当前包含 13 页。

网页不得根据旧版 HTML 自行补写或混合旧内容。正文、标题、图片和顺序均以 DOCX 为准；仅允许为网页可读性增加目录锚点、容器、按钮和响应式样式。

## 3. 采用方案

采用响应式 HTML，而不是将 Word 转成整页图片或嵌入 PDF。

原因：

- 文字可搜索、可复制，并能被浏览器和辅助技术正确识别；
- 电脑和手机均可自适应阅读；
- 图片可以保持清晰并按正文位置展示；
- 不依赖浏览器对 Office 或 PDF 内嵌阅读器的兼容性。

## 4. 页面结构

### 4.1 赛事页面外层

保留现有公开赛事页面的页头、赛事海报和“报名流程”标题。海报下方继续使用现有报名指南嵌入区域，不改变赛事选择和公开页面路由。

### 4.2 指南顶部

指南内容顶部显示：

- `2026年温州市青少年航空航天创新比赛`；
- `赛事用户管理系统使用说明文档`；
- `市级选拔赛报名阶段`；
- DOCX 中的编制单位、编制时间和系统登录网址；
- “下载 PPT 图文指南”按钮。

下载按钮直接下载原始 `注册指南(1).pptx`，使用清晰的中文文件名，不打开第三方页面。

### 4.3 目录

根据 DOCX 的主要章节建立页内目录：

1. 阅读前提示；
2. 名词概念介绍；
3. 操作前注意事项；
4. 账号注册流程操作说明。

点击目录项滚动到相应章节。目录只用于导航，不修改原文层级。

### 4.4 正文

正文按照 DOCX 中的实际顺序渲染：

- 保留全部非空正文段落；
- 保留章节标题、编号、列表和强调关系；
- 10 张正文图片按其在 DOCX 正文中的锚点位置展示；
- 图片添加与上下文一致的替代文本；
- 不显示 Word 自动目录中的点线和页码；
- 不显示无语义的孤立页码或版面占位符；
- 不保留旧版 HTML 中“第一块：注册登录流程”“第二块：正式报名流程”等旧结构，除非这些文字本身存在于 DOCX。

## 5. 静态资源与实现边界

继续使用现有 `/registration-flow/` 静态页面作为嵌入内容，以降低对公开赛事页面组件的影响。

静态资源包括：

- 新版 `registration-flow/index.html`；
- 从 DOCX 提取并按正文顺序命名的 10 张图片；
- 原始 PPTX 下载文件，发布名称为 `温州市青少年航空航天创新比赛注册指南.pptx`；
- 现有用于嵌入高度同步的脚本。

旧版流程图片和旧版 HTML 文案不再被页面引用。实施时删除旧版 6 张流程图片，避免无效资源继续进入生产构建；保留并改写现有 `index.html` 和 `embed.js` 文件路径，保证公开路由兼容。

## 6. 响应式与视觉规范

- 延续官网蓝白配色、圆角卡片和深蓝标题；
- 正文区域控制最大阅读宽度，避免桌面端单行过长；
- 章节之间保持明确留白，标题层级清晰；
- 图片宽度不超过正文容器，保持原始宽高比；
- 手机端使用单栏布局，目录和下载按钮允许换行；
- 手机端不得出现横向滚动条；
- 保证文字字号和按钮触控区域满足手机阅读需求。

## 7. 错误与降级处理

- PPTX 下载资源必须随 Web 构建一同发布；下载资源缺失时，自动测试必须失败；
- 图片缺失时，自动测试必须失败，页面仍保留替代文本；
- 嵌入高度继续由现有 `ResizeObserver` 机制同步，避免内外双滚动条；
- 浏览器不支持 `ResizeObserver` 时，保留可阅读的最小高度，不阻止正文访问。

## 8. 测试与验收

### 8.1 自动测试

- 报名指南 iframe 仍指向 `/registration-flow/?embed=1`；
- 新 HTML 包含 DOCX 的文档主标题和四个主要章节；
- 新 HTML 不再包含旧版两块流程结构；
- 10 张正文图片均存在并被 HTML 引用；
- PPTX 文件存在，下载链接带有 `download` 属性；
- Web 完整测试和生产构建通过。

### 8.2 浏览器验收

- 线上赛事海报保留；
- 海报下方完整显示新版注册指南；
- 目录跳转正确；
- 文字、图片顺序与 DOCX 一致；
- PPT 下载按钮可见且下载文件名正确；
- 桌面端和手机端无明显溢出、遮挡或双滚动条；
- 线上版本号、API 版本和容器发布版本一致。

## 9. 不在本次范围内

- 不修改 DOCX 或 PPTX 的业务文案；
- 不实现在线编辑 Word；
- 不实现 PPT 在线播放；
- 不改变报名资格、用户权限、短信验证或组织审核流程；
- 不调整其他公开内容页面。
