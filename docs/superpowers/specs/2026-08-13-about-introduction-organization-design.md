# 大赛介绍与组织机构页面设计

## 目标

在温州市青少年航空航天创新比赛的“大赛简介”页面补充正式的“大赛介绍”和“组织机构”内容，使页面信息完整、层级清晰，并保持现有海报与蓝紫色视觉体系。

## 信息结构

- 仅对赛事 `wz-aerospace-2026` 生效，不改变其他赛事的通用降级文案。
- 比赛时间、比赛地点、报名截止三个事实卡片之后，依次展示“大赛介绍”和“组织机构”。
- 两个新增模块均占满内容区一整行，适合阅读较长正文。
- 原有“赛事主题”“举办宗旨”“参赛对象”继续保留在其后，并保持双列卡片布局。
- 窄屏继续使用现有单列布局，不增加新的横向滚动区域。

## 内容规则

- “大赛介绍”和“组织机构”使用用户提供的正式文字，不缩写、不改写机构名称。
- 数据继续集中维护在赛事专属内容文件中，由公共赛事内容构建器输出。
- 内容构建器增加一个明确的全宽布局标记，页面组件只负责根据该标记添加样式类，避免通过标题名称硬编码布局。

## 验收标准

- 页面可看到两个新增标题及完整正文。
- 两个新增卡片在桌面端均占满两列，原有三个短卡片仍采用双列栅格。
- 移动端所有卡片按单列展示且无横向溢出。
- 其他赛事和“大赛章程”等页面不受影响。
